# Jodhpur Poker – No-Limit Texas Hold'em

Fully playable multiplayer No-Limit Hold'em with authentic Jodhpur (Blue City) graphics.

## Features

- Standard **No-Limit Texas Hold'em** rules
- Up to **9 players**
- Create room + share invite code (PeerJS – free, no paid servers)
- Starting stack **$10,000** each • Blinds $50 / $100
- Beautiful **Jodhpur-themed card backs** featuring Mehrangarh Fort & Blue City
- Custom felt table with Jodhpur emblem
- Realistic table layout, hole cards, community cards, betting UI
- Works on phone and desktop
- Host free on **GitHub Pages**

## Files

- `index.html` – the complete game
- `card-back.jpg` – custom Jodhpur card back (Mehrangarh Fort)
- `table-felt.jpg` – elegant felt with fort emblem
- `README.md`

## Deploy

1. Upload **all files** in this folder to a GitHub repository
2. Settings → Pages → Deploy from main (root)
3. Share the URL + room code with friends

MIT – free to use and host.
